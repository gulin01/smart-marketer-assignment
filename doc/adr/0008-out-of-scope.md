# ADR 0008 — 범위 밖 항목과 알려진 한계

- 상태: 채택
- 날짜: 2026-09-11

## 배경

3일 과제에서 무엇을 하지 않았는지 적어두지 않으면, 읽는 사람은 그것이 누락인지
판단인지 알 수 없다. 아래는 모두 **의도적인 판단**이다.

## 하지 않기로 한 것

### 제출 중복 제거
같은 방문자가 여러 번 제출하면 여러 건으로 기록된다. "중복" 의 정의(같은 방문자?
같은 이메일? 같은 시간대?)가 사업 정책이지 기술 문제가 아니며, 원본을 보존하면
나중에 어떤 정책이든 적용할 수 있지만 그 반대는 불가능하다.
전환율이 1을 넘을 수 있는 이유이기도 하다 ([[0004]]).

### 봇 필터링
IP + slug 기준 분당 10회 제한만 둔다. CAPTCHA, 허니팟, 디바이스 지문은 넣지 않았다.
리드 매그넷에서 과도한 마찰은 전환율을 직접 떨어뜨리므로, 실제 스팸 양을 본 뒤
결정할 문제다.

### 인메모리 레이트 리밋
제한 상태가 프로세스 메모리에 있다. 인스턴스를 여러 개 띄우면 실질 한도가
인스턴스 수만큼 늘어나고, 재시작하면 초기화된다. 단일 프로세스 전제에서는
충분하며, 필요해지면 Redis나 `RateLimit` 테이블로 옮기면 된다.

### 봇/프리페치 방문 제외
`<link rel=prefetch>` 나 크롤러의 페이지 로드도 방문으로 집계된다. User-Agent를
저장해 두었으므로 사후 필터링이 가능하다.

### 차트 라이브러리
채널 4개짜리 막대 그래프에 recharts를 추가하지 않고 div로 그렸다. 클라이언트
번들과 의존성을 늘릴 만한 복잡도가 아니다.

### 그 외
- 운영자 계정 관리(추가·권한·비밀번호 변경) — 요구사항은 1계정이다 ([[0002]])
- 템플릿 버전 관리 — 수정 시 새 템플릿을 올리는 방식
- 제출 알림(이메일/웹훅)
- 페이지네이션 — CRM 목록은 최근 500건까지 표시하고, 전량은 CSV로 제공한다
- 소프트 삭제 / 감사 로그

## 배포에 대하여

데모 배포(Vercel + Neon)는 수행하지 않았다. 계정과 도메인 자격증명이 필요하기
때문이다. 다만 [[0003]] 의 오리진 격리를 실제로 성립시키려면 `FORM_HOST` 를
`APP_HOST` 와 **다른 도메인**으로 설정해야 한다. 이 설정은 환경변수만으로
가능하며, 변경 후 `POST /api/forms/:id/links` 로 링크를 재생성하면 된다.

## 알려진 한계 요약

| 항목 | 영향 | 대응 경로 |
|---|---|---|
| 제출 중복 미제거 | 전환율 > 100% 가능 | 정책 확정 후 집계에서 처리 |
| 인메모리 레이트 리밋 | 다중 인스턴스에서 느슨해짐 | Redis/DB로 이전 |
| 쿠키 차단 방문자 | 방문자 수 과소, 전환율 과대 | 서버측 핑거프린팅(프라이버시 검토 필요) |
| 채널 값 조작 가능 | 귀속 왜곡 | 서명된 토큰으로 대체 가능 |
| 개발 환경 동일 오리진 | 방어 1겹 부재 | 운영에서 FORM_HOST 분리 |
