# ADR 0008 — 범위 밖 항목과 알려진 한계

- 상태: 채택
- 날짜: 2026-09-11

## 배경

3일 과제에서 무엇을 하지 않았는지 적어두지 않으면, 읽는 사람은 그것이 누락인지
판단인지 알 수 없다. 아래는 모두 **의도적인 판단**이다.

## 하지 않기로 한 것

### 제출 중복 제거
같은 방문자가 여러 번 제출하면 여러 건으로 기록된다. "중복" 의 정의(같은 방문자?
같은 이메일? 같은 시간대?)가 사업 정책이지 기술 문제가 아니며, 원본을 보존하면
나중에 어떤 정책이든 적용할 수 있지만 그 반대는 불가능하다.
전환율이 1을 넘을 수 있는 이유이기도 하다 ([[0004]]).

### 봇 필터링
IP + slug 기준 분당 10회 제한만 둔다. CAPTCHA, 허니팟, 디바이스 지문은 넣지 않았다.
리드 매그넷에서 과도한 마찰은 전환율을 직접 떨어뜨리므로, 실제 스팸 양을 본 뒤
결정할 문제다.

### 인메모리 레이트 리밋
제한 상태가 프로세스 메모리에 있다. 인스턴스를 여러 개 띄우면 실질 한도가
인스턴스 수만큼 늘어나고, 재시작하면 초기화된다. 단일 프로세스 전제에서는
충분하며, 필요해지면 Redis나 `RateLimit` 테이블로 옮기면 된다.

### 봇/프리페치 방문 제외
`<link rel=prefetch>` 나 크롤러의 페이지 로드도 방문으로 집계된다. User-Agent를
저장해 두었으므로 사후 필터링이 가능하다.

### 차트 라이브러리
채널 4개짜리 막대 그래프에 recharts를 추가하지 않고 div로 그렸다. 클라이언트
번들과 의존성을 늘릴 만한 복잡도가 아니다.

### 그 외
- 운영자 계정 관리(추가·권한·비밀번호 변경) — 요구사항은 1계정이다 ([[0002]])
- 템플릿 버전 관리 — 수정 시 새 템플릿을 올리는 방식
- 제출 알림(이메일/웹훅)
- 페이지네이션 — CRM 목록은 최근 500건까지 표시하고, 전량은 CSV로 제공한다
- 소프트 삭제 / 감사 로그

## 배포 (완료)

데모를 Vercel + Neon(us-east-1, 함수 리전과 동일)에 배포했다. **[[0003]] 의
오리진 분리를 실제로 성립시켰다** — 관리 화면과 공개 폼이 서로 다른 도메인에서
서빙된다.

| | |
|---|---|
| 관리 화면 | `https://glowup-admin-app.vercel.app` |
| 공개 폼 | `https://glowup-forms.vercel.app` |

세션 쿠키는 관리 도메인에 호스트 스코프로 묶여 있어 폼 도메인에는 존재하지 않는다.
실제 배포에서 확인했다: 폼 도메인에서 관리 API를 호출하면 401이고, 관리 도메인의
쿠키는 다른 도메인 요청에 실리지 않는다.

런타임 `DATABASE_URL` 은 Neon의 **풀링된** 연결을 쓴다 — 서버리스 함수마다 연결을
열면 한도가 금방 소진되기 때문이다. 마이그레이션은 세션 레벨 연결이 필요하므로
**비풀링(direct)** 연결로 실행한다.

### 알려진 운영 이슈: 세 번째 도메인

Vercel이 자동 생성한 `smart-marketer-assignment.vercel.app` 도 같은 앱을 서빙한다.
`APP_HOST`/`FORM_HOST` 는 위 두 도메인으로 고정되어 있으므로, 이 세 번째 도메인에서
접속하면 CSP의 `frame-ancestors` 에 해당 출처가 없어 **iframe 이 차단된다** —
공개 폼과 템플릿 미리보기가 빈 화면으로 보인다.

보안 문제가 아니라 CSP가 안전한 방향으로 실패하는 것이지만, 사용자에게는 고장으로
보인다. 이 도메인은 관리 도메인으로 **리다이렉트**시켜야 한다.

## 알려진 한계 요약

| 항목 | 영향 | 대응 경로 |
|---|---|---|
| 제출 중복 미제거 | 전환율 > 100% 가능 | 정책 확정 후 집계에서 처리 |
| 인메모리 레이트 리밋 | 다중 인스턴스에서 느슨해짐 | Redis/DB로 이전 |
| 쿠키 차단 방문자 | 방문자 수 과소, 전환율 과대 | 서버측 핑거프린팅(프라이버시 검토 필요) |
| 채널 값 조작 가능 | 귀속 왜곡 | 서명된 토큰으로 대체 가능 |
| 개발 환경 동일 오리진 | 방어 1겹 부재 | 운영에서는 분리 완료 (위 참고) |
| 세 번째 vercel.app 도메인 | 해당 출처에서 iframe 차단 | 관리 도메인으로 리다이렉트 |
