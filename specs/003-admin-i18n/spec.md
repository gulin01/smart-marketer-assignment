## 문제

관리 화면이 한국어로만 되어 있다. 한국어를 읽지 못하는 사람은 평가도 운영도 할 수
없다.

## 목표

운영자가 관리 화면 언어를 한국어와 English 사이에서 전환할 수 있고, 그 선택이
다음 방문에도 유지된다.

## 범위

**포함**
- 관리 화면 전체 문구 (내비게이션, 표, 폼, 빈 상태, 버튼)
- API 오류 메시지
- 헤더의 전환 버튼, 선택 유지

**제외**
- **공개 폼** — 한국어 고정. 운영자의 표시 설정이 방문자 화면에 새면 안 된다
- URL 기반 로케일 (`/ko/...`) — 아래 결정 참조
- 자동 언어 감지 — 명시적 선택과 충돌한다

## 동작

### 성공 경로
1. 헤더의 `EN` 을 누른다.
2. 화면 전체가 즉시 영어로 바뀐다.
3. 다른 페이지로 이동해도 영어가 유지된다.
4. 다시 방문해도 영어다.

### 실패 경로
| 상황 | 결과 |
|---|---|
| 지원하지 않는 로케일 요청 | 400 |
| 쿠키 없음 / 손상 | 한국어(기본값)로 조용히 처리 |
| 요청 컨텍스트 밖에서 메시지 조회 | 기본 로케일로 폴백 — 요청 자체를 실패시키지 않는다 |

## 성공 기준

- [x] 첫 렌더부터 올바른 언어 — 깜빡임 없음
- [x] 두 로케일의 **키 집합이 동일**하다 (누락은 타입 오류)
- [x] 두 로케일의 **`{placeholder}` 집합이 동일**하다
- [x] 공개 폼은 로케일 쿠키와 무관하게 한국어
- [x] 기존 URL·테스트·배포된 링크가 그대로 동작
